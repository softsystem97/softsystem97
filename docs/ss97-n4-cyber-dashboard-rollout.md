# SS97 — Dashboard technicien cybersécurité N4

Le tableau de bord sous /ss97-tech-cyber est alimenté par les missions CYBER ayant un mandat écrit, une approbation indépendante, un profil freelance ACTIVE et un ticket avec affectation encore valide.

Il affiche des indicateurs, les missions personnelles, les comptes rendus et les expertises consultables pour une revue N4. Les actions réelles de mission restent gérées par l'API TECH OS, et les validations par l'API Cyber Assessment. Ce tableau **n'active aucun compte et n'accorde aucun rôle**.

## Préconditions de fonctionnement
1. Frappe Cloud déployé avec ERPNext/Frappe v16 et migrations exécutées.
2. Drapeaux privés validés: ss97_tech_os.enabled; pour les tickets, ss97_ticket_bridge.enabled et compatibility_confirmed.
3. Examen N4 : banque privée d'au moins 40 questions actives et vérifiées; le dossier doit avoir un examen PASSED.
4. Pièce d'identité et justificatif de compétence privés et validés; contrat signé et vérifié; rôle exclusif SS97 Technicien N4.
5. Double validation du profil; mandat écrit, affectation Issue active, second validateur pour chaque mission sensible.
6. Recette avec N4 actif, N4 non habilité, N2, N3, Guest, compte suspendu, client et révocation d'assignation.
7. Test d'un ticket jusqu'au compte rendu et à la validation client, sans vraie intervention non autorisée.

Ni la fusion GitHub ni les tests hors ligne ne démontrent l'installation Frappe Cloud ou la réception des notifications. Aucune réponse d'examen, identité client, mot de passe ou secret Stripe dans ce dépôt.
