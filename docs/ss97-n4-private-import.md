# Import confidentiel des questions N4

Ce module de Soft System 97 reçoit un CSV via l'upload privé natif Frappe.
L'endpoint exige un System Manager et un fichier CSV privé, non rattaché,
créé par le même responsable. Il vérifie les colonnes, les 40 questions
CYBER, les options, les doublons et is_active=0. Aucune question n'est rendue
active et aucune réponse n'est envoyée au navigateur.

Le formulaire est présent dans l'espace administrateur TECH OS. Les questions
et leurs corrigés ne figurent jamais dans GitHub, les tests GitHub ou les
messages de contrôle. La revue professionnelle et les signatures restent une
étape distincte ; l'import ne remplace pas cette validation.

Avant de démarrer l'examen, 40 questions doivent être approuvées par un expert
N4 puis activées par un responsable via le DocType privé. Vérifier le rapport
de préparation après activation. Aucune mission ni rôle ne sont créés.
